Bugs Fixed
**********

- **Commands:** Fixed a bug where generator commands did not sort the imports of a template with CRLF line endings.
- **Format:** Fixed ``XMLFormatter`` so that an array key that becomes empty after
  sanitization no longer triggers a ``ValueError``; the fallback tag name ``item``
  is used instead. Values that cannot be converted to a string, such as objects
  not implementing ``Stringable``, now throw a ``FormatException`` instead of a
  fatal ``Error``.
- **Helpers:** Fixed a regression in v4.7.5 where ``set_value()`` threw a
  ``TypeError`` when the default value was not a string or an array, such as
  an integer, a float, ``null``, or a ``Stringable`` object. Such values are
  now converted to a string.
- **HTTP:** Fixed stale ``$_REQUEST`` values after ``SiteURIFactory`` normalizes GET parameters, so ``Validation::withRequest()`` reads the normalized values while unrelated REQUEST entries are preserved.
- **HTTP:** Fixed a bug where ``IncomingRequest::isSecure()`` did not
  recognize ``https`` in the ``X-Forwarded-Proto`` header from a trusted
  proxy when the value contained uppercase letters or surrounding
  whitespace, or was represented as a single-element array.
- **Security:** Fixed a bug where a valid JSON request body that is not an object
  (for example a JSON array) was corrupted after CSRF verification when the
  token was sent via the ``X-CSRF-TOKEN`` header.

See the repo's
`CHANGELOG.md <https://github.com/codeigniter4/CodeIgniter4/blob/develop/CHANGELOG.md>`_
for a complete list of bugs fixed.
