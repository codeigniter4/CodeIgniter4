# Contributing to CodeIgniter4

CodeIgniter is a community driven project and accepts contributions of
code and documentation from the community.

## Responsibility for Contributions

AI-assisted contributions are welcome, but contributors remain responsible
for everything they submit.

Before opening a pull request, you must:

- Review and understand all proposed changes.
- Explain the problem being addressed and why the proposed solution is appropriate.
- Verify the changes, run relevant tests, and describe what you tested,
  including any limitations.
- Be prepared to answer review questions and revise your contribution.

These requirements apply regardless of the tools used. AI-generated
explanations and passing CI checks do not replace your own review.

Automated submissions without meaningful human review are not accepted.
Project-approved automation, such as dependency update bots, is exempt
from this submission requirement.

Maintainers may close pull requests without detailed code review when
the problem is unclear, the changes have not been adequately verified,
or the contributor cannot explain them.

We do not require AI tool disclosures, prompts, or chat histories.

## Open Pull Request Limit

Contributors without write access may have up to three pull requests
open in this repository at the same time, including drafts.
Maintainers may grant exceptions to trusted contributors.

Please address feedback on your existing pull requests before opening
additional ones.
