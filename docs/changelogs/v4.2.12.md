# Version 4.2.12

Release Date: January 9, 2023

**4.2.12 release of CodeIgniter4**

## Bugs Fixed

- Fixed a bug where `Request::getIPaddress()` caused an error on CLI.
- Fixed `link_tag()` missing `type="application/rss+xml"`.
- Fixed a bug where `spark migrate:status` showed incorrect filenames when the format was `Y_m_d_His_`.
- Fixed an error when `Model::save()` saves an object if `$useAutoIncrement` is false.

See the repo's [CHANGELOG_4.2.md](https://github.com/codeigniter4/CodeIgniter4/blob/develop/changelogs/CHANGELOG_4.2.md) for a complete list of bugs fixed.
