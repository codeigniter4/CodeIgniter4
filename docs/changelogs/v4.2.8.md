# Version 4.2.8

Release Date: October 30, 2022

**4.2.8 release of CodeIgniter4**

## Deprecations

- The third parameter `$returnResponse` of `CodeIgniter::handleRequest()` is deprecated.

## Bugs Fixed

- Fixed a bug where the `CodeIgniter\HTTP\IncomingRequest::getPostGet()` and `CodeIgniter\HTTP\IncomingRequest::getGetPost()` methods didn't return values from the other stream when `index` was set to `null`.
- Fixed a bug where `binds` weren't cleaned properly when calling `CodeIgniter\Database\Postgre::replace()` multiple times in the same context.
- Fixed a bug where `CodeIgniter\Database\SQLSRV\PreparedQuery::_getResult()` was returning a bool value instead of the resource.
- Fixed a bug in the error handler where, when the callback could not process the error level, it did not pass the error to PHP's standard error handler.

See the repo's [CHANGELOG_4.2.md](https://github.com/codeigniter4/CodeIgniter4/blob/develop/changelogs/CHANGELOG_4.2.md) for a complete list of bugs fixed.
