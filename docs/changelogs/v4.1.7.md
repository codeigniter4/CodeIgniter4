# Version 4.1.7

Release Date: January 9, 2022

**4.1.7 release of CodeIgniter4**

## BREAKING

- Because `FILTER_SANITIZE_STRING` has been deprecated since PHP 8.1, the output of `get_cookie()`, which uses it when `$xssClean` is true, has changed. Now it uses `FILTER_SANITIZE_FULL_SPECIAL_CHARS`. Note that using XSS filtering is a bad practice. It does not prevent XSS attacks perfectly. Using `esc()` with the correct `$context` in the views is recommended.
