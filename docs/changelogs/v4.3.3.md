# Version 4.3.3

Release Date: March 26, 2023

**4.3.3 release of CodeIgniter4**

## SECURITY

- **Email:** Added missing TLS 1.3 support.
- **Text Helper:** The `random_string()` types **alpha**, **alnum**, **numeric** and **nozero** are now cryptographically secure.

## Bugs Fixed

- **Config:** Added missing `Config\Encryption::$cipher`.
- **UserGuide:** Fixed the sample code for [Configuration to Maintain Compatibility with CI3](../libraries/encryption.md#configuration-to-maintain-compatibility-with-ci3).
- **UserGuide:** Added a missing breaking change in `uri_string()` in [ChangeLog](v4.3.2.md#uri_string) and [Upgrading Guide](../installation/upgrade_432.md#uri_string) v4.3.2.

See the repo's [CHANGELOG.md](https://github.com/codeigniter4/CodeIgniter4/blob/develop/CHANGELOG.md) for a complete list of bugs fixed.
