# Version 4.5.5

Release Date: September 7, 2024

**4.5.5 release of CodeIgniter4**

## Bugs Fixed

- **URL Helper:** The bug where the regular expression in `auto_link()` was outdated has been fixed. As a result of this fix, the same regular expression as CodeIgniter 3 is now used.

See the repo's [CHANGELOG.md](https://github.com/codeigniter4/CodeIgniter4/blob/develop/CHANGELOG.md) for a complete list of bugs fixed.
