# Version 4.2.1

Release Date: June 16, 2022

**4.2.1 release of CodeIgniter4**

## BREAKING

### Behavior Changes

- Guessing the file extension from the MIME type has been changed if the proposed extension is not valid. Previously, the guessing would terminate early and return `null`. Now, if a proposed extension is given and is invalid, the MIME guessing will continue checking using the mapping of extension to MIME types.
- If there is a cookie with a prefixed name and a cookie with the same name without a prefix, the previous `get_cookie()` had the tricky behavior of returning the cookie without the prefix. This behavior has now been fixed as a bug. See [Upgrading](../installation/upgrade_421.md#get_cookie) for details.
