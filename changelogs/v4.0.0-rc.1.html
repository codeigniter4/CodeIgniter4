Version 4.0.0-rc.1

Release Date: Sep 3, 2019

RC.1 release of CodeIgniter4

  • Enhancements

  • App Changes

  • Message Changes

  • Changed Files

  • PRs merged

Enhancements

  • CI3 Email ported to CI4

  • Encryption (basic) added

  • Migrations refactored and streamlined for more holistic functionality (BC)

  • Added convert() to ImageHandlerInterface

  • Disabled debug toolbar for downloads

  • CLI commands return an error code now (“spark” changed)

  • RESTful controllers added to shorten dev time for RESTful APIs

  • Added RouteCollection::presenter() as part of the RESTful support

App Changes

  • Added app/Common.php to make it easier to override common functions

  • Config/Email and Config/Encryption added

  • Config/Migration modified, and has different settings

  • app/Controllers/Home.php fixed, removing unnecessary model reference

Message Changes

  • Migration has new & modified messages

  • Messages now have a RESTful set
